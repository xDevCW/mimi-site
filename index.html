MIAR Studio Tools

MIAR Studio Tools is a small private application that supports the production of an animated YouTube channel run by a single owner. It is not offered to the public and has no sign-up.

What the app does

  • Uploads finished videos, with their titles, descriptions and thumbnails, to the owner's own YouTube channel through the YouTube Data API.
  • Reads the channel's own statistics (views, watch time and similar public and analytics figures) so the owner can track how videos perform.
  • Sends the owner a private summary of those figures, for example as a daily message.

Who uses it

Only the channel owner signs in, with the owner's own Google account. The app does not read, collect or store data about any other person's account or channel.

YouTube API Services

The app uses YouTube API Services. By using it, the owner is bound by the YouTube Terms of Service and the Google Privacy Policy.
